# 执行前检查清单

每次分析、开单、改止损、复盘前必须先看这张清单。

## 1. 账户状态

- 是否有非零持仓。
- 是否有普通挂单。
- 是否有条件单/止损单。
- 如果已有仓位，先判断是否需要保护，不先找新单。

## 2. 大盘过滤

- BTC 15m/1h/4h 是否强空。
- 如果 BTC 三周期强空，降低所有多单胜率。
- BTC 若在急跌后 15m 超卖，不追空，等反抽失败。

## 3. 交易触发

只允许三类试单：

- 突破后站稳。
- 回踩关键位不破。
- 止损后重新形成新结构。

禁止：

- 只因为 1m 拉升就追。
- 止损后马上同方向复仇。
- 没有止损就开仓。
- 因为消息或 KOL 一句话直接下单。

## 4. 仓位规则

- 默认每笔约 5U 保证金。
- 默认 2x 杠杆。
- 特殊机会不超过 10U 保证金，必须重新确认。
- 每笔都要写清楚：保证金、杠杆、名义仓位、止损距离、预估亏损。

## 5. 胜率规则

- 55% 以下：不做。
- 55%-58%：可以小试。
- 58%-62%：优先机会。
- 62% 以上：重点机会，但仍必须有止损。

胜率是主观估计，直到日志样本足够前不能当成真实概率。

## 6. 下单确认

没有用户明确确认，不开仓、不平仓、不加仓、不撤单、不改止损。

确认格式示例：

```text
确认 HYPE 多 0.15 止损 67.30
确认 BNB 止损改到 732.8
```
