# TXJ Contract Knowledge Base

这是我们的本地合约交易知识库，用 Obsidian 打开这个文件夹即可。

核心目标：

- 把每笔交易、复盘、规则、币种剧本放在本地 Markdown。
- 每次分析和操作前，先读 `00_执行前必读/执行前检查清单.md`。
- 交易结束后，同步更新复盘、Excel 和规则。
- 任何规则都服务于风控，不保证盈利。

当前阶段：

- 默认每笔约 5U 保证金。
- 默认 2x 杠杆。
- 主观胜率 55% 以上可考虑小试，但必须有触发位和止损。
- 连续亏损或连续被洗后，先复盘再继续。
